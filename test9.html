Placement Manager Order and Trigger Test

This page tests campaign script order when the Placement Manager loads before the Web Embed target exists.

Expected saved order: Inactive 10 → Embed → On Scroll → On Click → Exit Intent → Total Time.

Check the Console messages labelled added and ran. Script loading order is separate from visible Lightbox opening.

For the initial comparison, disable Test Mode on all destinations. For the later Test Mode check, add ?NGX_PM_TEST to this page's URL.

Section 1 — Lightbox trigger checks

  • Exit Intent: On desktop, move the pointer out through the top of the page.
  • On Click: Click the dedicated button at the top of this page.
  • On Scroll: Scroll the parent page past the configured threshold.
  • Inactive Time: Stop interacting for the configured duration.
  • Total Time: Keep interacting while waiting for the configured duration.

Existing settings: On Scroll at 50%, Inactive Time at 10 seconds and Total Time at 20 seconds. Confirm these in the publishing destination editor.

Mixed Embed/Lightbox pages may start Lightbox timers later while waiting for the Embed target. Record the timing separately from the ordering result.
