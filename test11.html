Same Campaign Multiple Destinations Test

This page tests one NextGen campaign published to the same Placement Manager using two separate Lightbox destinations.

Test configuration

  • Destination 1 should use the Page Load trigger and appear immediately.
  • Destination 2 should use a Scroll trigger and remain hidden until the configured scroll depth is reached.
  • Both destinations should belong to the same campaign and the same Placement Manager.
  • Configure each destination with a different position, size or transparency so they can be distinguished.
