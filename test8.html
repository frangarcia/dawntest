Section 1 — Variable and API tests

The page starts with window.test = false and window.DZMP.site_score = 0. Refreshing resets these JavaScript values.

For the basic test, configure a Lightbox with a Page Load trigger and a JavaScript Variable rule: test equals true.

Once the Console shows QA: Grow API ready, run: 

test = true;
NGX.api('evaluate:display:rules');

For the nested-variable test, configure a rule: DZMP.site_score greater than 10. Then run: 

DZMP.site_score = 11;
NGX.api('evaluate:display:rules');

Refresh between independent test scenarios. Refreshing does not clear frequency-cap or consent storage.

Section 3 — SPA route tests

Configure one Lightbox with Current Page URL containing qaRoute=first, and another containing qaRoute=second.

Run this in the Console to change the URL without reloading. It preserves the current path and Test Mode parameter. 

var qaRouteUrl = new URL(location.href);
qaRouteUrl.searchParams.set('qaRoute', 'first');
history.pushState({}, '', qaRouteUrl);
NGX.api('evaluate:display:rules');

Close the first Lightbox, then switch routes:

NGX.api('lightbox:close');

var qaRouteUrl = new URL(location.href);
qaRouteUrl.searchParams.set('qaRoute', 'second');
history.pushState({}, '', qaRouteUrl);
NGX.api('evaluate:display:rules');

To remove the test route: 

var qaRouteUrl = new URL(location.href);
qaRouteUrl.searchParams.delete('qaRoute');
history.pushState({}, '', qaRouteUrl);
NGX.api('evaluate:display:rules');
