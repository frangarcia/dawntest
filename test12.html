Placement Manager Unpublish and Republish Test

This page tests whether existing Lightbox destinations continue working after they are unpublished and republished.

Go to the top section Go to the middle Go to the bottom

Test configuration

  • Lightbox A remains Published throughout the test and acts as the control.
  • Lightbox B is unpublished and then the same destination is republished.
  • Lightbox C is unpublished and then the same destination is republished.
  • All three destinations are assigned to the same Placement Manager.
  • Configure each Lightbox with different content and a different position so they can be identified.

Section 1 — Top of page

All three Lightboxes should initially appear when configured with the Page Load trigger.

Give each Lightbox a visible identifier such as A, B or C so that its publishing state can be verified.

Section 2 — First scroll area

This section provides additional page height in case one of the Lightboxes needs to be tested with a scroll trigger later.

Cheesecake muffin lollipop pastry. Soufflé sugar plum caramels, cupcake, toffee and cotton candy.

Section 3 — Middle of page

After Lightboxes B and C are unpublished, only control Lightbox A should continue to display.

The Placement Manager loader must continue to return successfully while A remains Published.

Section 4 — Republish verification

After republishing the same B and C destinations, all three Lightboxes should display again.

Their Placement Manager assignments, triggers, Test Mode, design settings and destination IDs should remain unchanged.

Section 5 — Bottom of page

Check the browser Console and Network panels for the Placement Manager request and each Lightbox destination request.
